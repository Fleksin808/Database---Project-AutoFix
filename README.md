# AutoFix Database

Databázový projekt informačního systému malé autodílny AutoFix vytvořený v rámci předmětu Databázové systémy.

## Popis projektu

Projekt řeší návrh databázového modelu pro malou autodílnu. Databáze eviduje zákazníky, vozidla, servisní zakázky, servisní úkony, mechaniky, díly, faktury, platby, servisní stání a odstavná místa.

## Obsah repozitáře

* create.sql – SQL skript pro vytvoření databázového schématu
* insert.sql – SQL skript pro vložení testovacích dat
* queries.sql – SQL dotazy pokrývající požadované kategorie
* relational_algebra.pdf – vybrané dotazy přepsané do relační algebry
* ERD.png – konceptuální/databázové schéma
* dokumentace.pdf – finální dokumentace projektu

## Použité technologie

* PostgreSQL
* SQL
* Relační algebra
* ER modelování
